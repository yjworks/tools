볼륨 평준화 (노멀라이즈)

너무 작게 녹음된 소리를 키우거나, 파일마다 들쭉날쭉한 음량을 같은 기준으로 맞춥니다. 처리 전후의 피크·평균 음량(RMS)·라우드니스(LUFS)를 숫자로 보여 줍니다.

사용법

  1. 파일을 넣으면 처리 전 피크·RMS·라우드니스를 잽니다.
  2. 맞출 기준과 목표값을 고르고 평준화 적용을 누릅니다. 올리거나 내린 양(dB)이 옆에 표시됩니다.
  3. 처리 전후를 들어 보고 WAV로 저장을 누릅니다. 여러 파일을 같은 기준·목표로 처리하면 음량이 서로 비슷해집니다.

세 가지 기준의 차이

디지털 소리의 크기는 가장 큰 값을 0 dBFS로 두고 그보다 얼마나 작은지를 음수 데시벨로 나타냅니다. -6 dB는 진폭이 절반이라는 뜻입니다.

  • 피크: 파일에서 가장 큰 순간이 목표(예: -1 dBFS)에 닿도록 전체를 같은 비율로 키웁니다. 찌그러짐이 절대 생기지 않지만, 한 번 튀는 소리(박수·기침)가 있으면 나머지는 별로 커지지 않습니다.
  • RMS: 전체 소리의 평균 세기(제곱 평균의 제곱근)를 맞춥니다. 사람이 느끼는 크기에 더 가깝습니다.
  • 라우드니스(LUFS): 방송 음량 기준인 ITU-R BS.1770 방식을 따라 사람 귀가 덜 민감한 낮은 소리를 덜 치고(K-가중), 조용한 구간은 빼고(게이트) 평균을 냅니다. 음성·음악의 "들리는 크기"를 맞추는 데 가장 알맞습니다. 이 도구의 계산은 인증된 측정기가 아닌 근사치이며, 표준 시험 신호(1 kHz 0 dBFS 사인파 → -3.01 LUFS)로 확인했습니다.

리미터

RMS·LUFS 기준으로 크게 키우면 큰 순간이 0 dBFS를 넘어 잘리며 "지지직" 찌그러집니다. 리미터는 그런 순간 바로 앞에서 음량을 잠깐 부드럽게 낮췄다가(5ms 미리 보기) 천천히 되돌려(80ms) 천장을 넘지 않게 합니다. 끄면 넘는 부분은 잘리고, 처리 후 결과에 잘린 샘플 수를 알려 줍니다.

결과는 16비트 WAV이며, 표본 주파수는 브라우저가 파일을 풀 때 쓰는 값(보통 44.1 kHz 또는 48 kHz)입니다.

자주 묻는 질문

목표값은 얼마로 하면 되나요?

정답은 쓰임새마다 다릅니다. 여러 파일의 크기만 비슷하게 하려면 모두 같은 LUFS 값(예: -16)으로 맞추면 됩니다. 올릴 곳에서 따로 음량 기준을 정해 두었다면 그 값을 넣으세요. 피크 기준은 -1 dBFS 정도가 무난합니다.

작은 목소리를 키웠더니 잡음도 커졌어요.

평준화는 파일 전체를 같은 비율로 키우므로 배경 잡음도 같이 커집니다. 먼저 이 사이트의 음성 잡음 제거로 잡음을 줄인 뒤 평준화하면 좋습니다.

MP3로 저장되나요?

브라우저에 MP3 인코더가 없어 WAV로만 저장합니다. WAV는 대부분의 편집기·플레이어에서 열리며, 필요하면 다른 프로그램으로 변환하세요.

파일이 서버로 가나요?

가지 않습니다. 측정과 처리 모두 이 브라우저 안에서 계산합니다.
