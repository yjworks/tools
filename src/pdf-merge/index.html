PDF 합치기

여러 PDF를 한 파일로 합칩니다. 쪽 순서를 끌어서 바꾸고, 필요 없는 쪽은 빼고, 옆으로 누운 쪽은 돌려서 저장할 수 있습니다. 사진도 쪽으로 넣을 수 있습니다.

🔒 업로드 없음 · 브라우저 안에서 처리

    쪽 순서

    쪽을 눌러 고른 뒤 아래 버튼으로 옮기거나 돌립니다. ⠿ 를 잡고 끌어도 됩니다. 점 색은 파일 목록의 색과 같습니다.

    사용법

    1. 합칠 PDF를 한꺼번에 놓습니다. 영수증 사진처럼 쪽으로 넣고 싶은 사진(JPG·PNG·WEBP)도 함께 놓을 수 있습니다.
    2. 파일 목록에서 파일 단위 순서를 정합니다. ▲▼ 버튼이나 왼쪽 ⠿ 손잡이로 옮기면 아래 쪽 목록이 파일별로 다시 정렬됩니다.
    3. 쪽 목록에서 쪽을 눌러 고르면 아래에 버튼 줄이 나타납니다. 여러 쪽을 함께 골라 한 번에 앞뒤로 옮기거나, 90도씩 돌리거나, 뺄 수 있습니다. PC에서는 쪽을 마우스로 바로 끌어 놓아도 되고, 휴대폰에서는 오른쪽 위 ⠿ 를 잡고 끕니다.
    4. 이름을 정하고 PDF 합치기를 누르면 한 파일로 저장됩니다. 원본 파일은 바뀌지 않습니다.

    합칠 때 무엇이 그대로 남고 무엇이 빠지나요

    이 도구는 쪽을 그림으로 바꾸지 않고, 쪽을 이루는 글자·글꼴·도형·사진 데이터를 그대로 새 파일로 옮깁니다(pdf-lib의 쪽 복사 기능). 그래서 글자는 합친 뒤에도 선택·검색되고, 화질도 원본과 같습니다. 파일 크기는 대체로 원본 크기의 합과 비슷하거나 조금 작습니다.

    항목합친 파일에서
    글자·사진·도형, 쪽 크기그대로
    쪽 회전원래 회전에 이 도구에서 돌린 각도를 더해 저장
    책갈피(목차 창)남은 쪽을 가리키는 것만 옮김. 뺀 쪽을 가리키던 항목은 빠지고, 그 아래 항목이 남아 있으면 첫 항목 쪽으로 이어 둠
    웹 주소 링크그대로
    문서 안 링크(목차를 누르면 해당 쪽으로 이동)같은 원본 안의 쪽이면 새 쪽 번호로 다시 연결. 가리키던 쪽을 뺐으면 그 링크는 지움
    입력 칸(서식 PDF)보이는 모양은 남지만, 합친 파일에서는 칸에 입력이 안 될 수 있음
    첨부 파일, 문서 전체에 걸린 스크립트, 쪽 번호 이름(i, ii…), 레이어 설정, 접근성 태그옮기지 않음
    전자서명합치면 파일 내용이 바뀌므로 서명은 효력이 없어짐

    암호가 걸린 PDF

    열 때 암호를 묻는 PDF와, 암호 없이 열리지만 인쇄·복사 제한이 걸린 PDF는 모두 내용이 암호화되어 있습니다. 이 도구가 쓰는 pdf-lib는 암호화를 풀지 못하므로, 그런 파일은 목록에 "암호화됨"으로 표시하고 합치지 않습니다. 권한이 있는 문서라면 원래 만든 프로그램에서 암호를 해제해 다시 저장한 뒤 넣어 주세요.

    자주 묻는 질문

    파일 순서를 바꿨더니 제가 섞어 둔 쪽 순서가 풀렸어요.

    파일 목록에서 순서를 바꾸면 쪽이 파일별로 다시 모입니다(한 파일 안의 순서와 회전은 유지). 여러 파일의 쪽을 섞어 배치하려면 파일 순서를 먼저 정한 다음 쪽 목록에서 옮기세요. 쪽 목록을 처음 상태로 돌리려면 쪽 되돌리기를 누릅니다.

    몇 개, 몇 쪽까지 합칠 수 있나요?

    따로 정한 제한은 없습니다. 다만 모든 작업이 기기 메모리 안에서 이뤄지므로, 합친 결과가 수백 MB에 이르면 휴대폰에서는 멈출 수 있습니다. 쪽 미리보기는 화면에 보이는 것부터 차례로 그리기 때문에 쪽이 많아도 목록은 바로 쓸 수 있습니다.

    사진은 어떤 크기로 들어가나요?

    기본은 A4 쪽 가운데에 비율을 지켜 맞추고, 가로로 긴 사진은 가로 A4로 넣습니다. "사진 크기 그대로"를 고르면 쪽 크기가 사진 크기(96dpi 기준)와 같아집니다. JPG와 PNG는 다시 압축하지 않고 넣고, WEBP와 회전 정보가 있는 JPG만 방향을 바로잡아 JPG(품질 92%)로 다시 저장합니다.

    파일이 서버로 전송되나요?

    아닙니다. 파일 읽기, 미리보기 그리기(pdf.js), 합치기(pdf-lib) 모두 지금 열어 둔 브라우저 안에서 처리합니다. 통계에는 파일 개수·쪽 수 같은 숫자만 남고 파일 이름과 내용은 기록하지 않습니다.

    합친 PDF가 원본들 크기의 합보다 작아졌어요. 뭔가 빠진 건가요?

    빠진 쪽이 없다면 정상입니다. 새로 저장하면서 여러 객체를 묶어 압축하는 방식(객체 스트림)을 쓰고, 어떤 쪽에서도 쓰지 않는 데이터는 저장하지 않기 때문에 조금 작아질 수 있습니다. 뺀 쪽에만 쓰이던 사진·글꼴도 함께 빠집니다.
