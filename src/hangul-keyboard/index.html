한영타 변환

한/영 키를 깜빡하고 dkssudgktpdy처럼 쳐 버린 글을 안녕하세요로 되돌립니다. 한글을 영문 자판 순서로 바꾸는 것도 됩니다.

사용법

  1. 잘못 친 글을 위 칸에 붙여 넣습니다. 자동 변환이 켜져 있으면 바로 결과가 나옵니다.
  2. 글에 한글이 섞여 있으면 한글 → 영타로, 영문만 있으면 영타 → 한글로 자동으로 고릅니다. 버튼을 누르면 방향을 직접 정할 수 있습니다.
  3. 결과 복사를 누르면 클립보드로 복사됩니다.

어떻게 되돌리나요

한국어 키보드 대부분은 두벌식 배열입니다. 영문 d 자리에 ㅇ, k 자리에 ㅏ가 있는 식이라, 영문으로 친 글자를 같은 자리의 자모로 바꾼 뒤 한글 조합 규칙대로 모으면 원래 글이 됩니다.

  • 받침 다음에 모음이 오면 받침이 다음 글자로 넘어갑니다: ekfrdmf → ㄷㅏㄹㄱㅇㅡㄹ → 닭을
  • 겹받침(ㄳ·ㄺ·ㅄ 등)과 겹모음(ㅘ·ㅝ·ㅢ 등)도 조합합니다: rkqt → 값, dhkd → 왕
  • 대문자는 Shift를 누른 것으로 봅니다: R → ㄲ, E → ㄸ, T → ㅆ, O → ㅒ, P → ㅖ
  • 숫자·기호·띄어쓰기는 그대로 둡니다.

자주 묻는 질문

영어 단어가 섞여 있으면 어떻게 되나요?

영문은 모두 한글 자판으로 보고 바꿉니다. 그래서 원래 영어였던 단어(예: ok)도 ㅐㅏ처럼 바뀝니다. 영어 부분은 결과에서 직접 되돌려 주세요.

세벌식 자판도 되나요?

지금은 두벌식 표준 배열만 지원합니다.

입력한 글이 어딘가로 전송되나요?

아니요. 변환은 이 페이지의 스크립트가 브라우저 안에서만 합니다. 비밀번호처럼 민감한 글이라도 밖으로 나가지 않습니다.
