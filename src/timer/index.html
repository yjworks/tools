전체화면 타이머 · 스톱워치

수업·발표·회의·운동에 쓰는 큰 숫자 타이머입니다. 전체화면으로 띄우고, 끝나면 소리로 알립니다.

05:00

단축키: Space 시작·멈춤 · R 초기화 · F 전체화면 · L 랩(스톱워치)

사용법

  1. 타이머에서 1·3·5·10분 버튼을 누르거나 분·초를 적고 이 시간으로를 누른 뒤 시작합니다.
  2. 전체화면을 누르면 숫자가 화면을 가득 채웁니다. 프로젝터나 TV에 띄울 때 좋습니다. Esc로 빠져나옵니다.
  3. 시간이 다 되면 삐 소리가 세 번 울리고 숫자가 깜빡입니다. 휴대폰이 무음·진동 모드이면 소리가 나지 않을 수 있으니 미리 소리 들어 보기로 확인하세요.
  4. 스톱워치는 시작한 뒤 랩을 누를 때마다 구간 기록이 쌓이고, 표를 복사해 엑셀 등에 붙일 수 있습니다.

시간이 밀리지 않게 재는 방법

많은 웹 타이머는 1초마다 숫자를 하나씩 줄입니다. 그런데 브라우저는 다른 탭을 보거나 화면이 바쁠 때 이런 반복 작업을 늦게 실행하기 때문에, 오래 켜 두면 몇 초씩 밀립니다.

이 타이머는 숫자를 세지 않고 시작한 순간의 시각을 기억해 두었다가 "지금 시각 − 시작 시각"을 매번 새로 계산합니다. 시각은 컴퓨터 시계를 바꿔도 영향을 받지 않는 performance.now()를 씁니다. 화면을 늦게 그리는 일이 있어도 다음에 그릴 때는 정확한 값이 나오므로 오차가 쌓이지 않습니다.

  • 카운트다운은 초 단위로 올려서 보여 줍니다. 5분 타이머는 5:00에서 시작해, 정확히 5분이 지난 순간 0:00이 됩니다.
  • 켜 둔 동안 화면이 꺼지지 않도록 지원하는 브라우저에서는 화면 꺼짐 방지(Screen Wake Lock)를 요청합니다. 멈추거나 초기화하면 풀립니다.
  • 알림음은 파일을 받지 않고 브라우저의 Web Audio로 그 자리에서 만듭니다.

자주 묻는 질문

다른 탭을 보고 있어도 끝나면 알려 주나요?

네, 시간 계산은 계속되고 탭 제목에도 남은 시간이 표시됩니다. 다만 브라우저가 숨은 탭의 작업을 1초 정도 늦출 수 있어 알림음이 조금 늦을 수 있고, 휴대폰은 화면이 꺼지거나 다른 앱으로 넘어가면 브라우저가 멈춰 소리가 나지 않을 수 있습니다. 중요한 알림은 화면을 켜 둔 채로 쓰세요.

아이폰에서 전체화면이 안 돼요.

아이폰 Safari는 웹 페이지의 전체화면 기능을 지원하지 않습니다. 그래서 대신 타이머 부분만 화면에 꽉 차게 보여 줍니다. 가로로 돌리면 숫자가 더 커집니다.

화면이 계속 꺼져요.

화면 꺼짐 방지는 브라우저가 지원할 때만 동작하고, 배터리 절약 모드에서는 거절될 수 있습니다. 위 안내 문구에 지원 여부가 나옵니다. 지원하지 않으면 기기 설정에서 화면 자동 꺼짐 시간을 늘려 주세요.

스톱워치 기록은 얼마나 정확한가요?

표시는 1/100초까지 합니다. 시간 계산 자체는 그보다 정밀하지만, 버튼을 누르는 손의 반응 시간(보통 0.1~0.3초)이 더 큰 오차가 됩니다. 공식 기록용이 아닌 연습·수업용으로 쓰세요.
